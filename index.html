IMPORT STORE LAYOUT

Tap to import a CSV or JSON store layout file

Adds aisle numbers to your grocery list

CSV FORMAT EXAMPLE
store_name,store_lat,store_lng,category,aisle
Walmart Supercenter,38.752,-90.726,Produce,1
Walmart Supercenter,38.752,-90.726,Dairy,3
Walmart Supercenter,38.752,-90.726,Meat,4
Walmart Supercenter,38.752,-90.726,Frozen Foods,10
Walmart Supercenter,38.752,-90.726,Snacks,7
JSON FORMAT EXAMPLE
[{
  "store_name": "Schnucks",
  "store_lat": 38.76,
  "store_lng": -90.75,
  "category": "Produce",
  "aisle": "1A"
}]

The app uses GPS to auto-select the right layout when you're near a store. Latitude and longitude narrow it down to the specific location.

ABOUT

Groceries is a local-first PWA. All your data stays on your device. The OpenAI API is used only to categorize items and is never stored.

To install on your iPhone: tap the Share button in Safari → Add to Home Screen.
